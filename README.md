# 🛒 Amazon Clone — Full Stack E-Commerce Web App

A modern **Amazon-inspired e-commerce web application** built using **React and Firebase**, allowing users to browse products, manage shopping carts, and simulate an online purchasing experience.

This project demonstrates frontend development, cloud integration, authentication handling, and deployment of a scalable web application.

---

## 🚀 Live Demo

👉  deployed link: https://amazonclone-teddy.netlify.app



## ✨ Features

* 🛍 Product browsing interface
* 🧺 Add/remove items from cart
* 🔐 User authentication
* 💳 Checkout workflow simulation
* ⚡ Real-time UI updates
* 📱 Fully responsive layout
* ☁️ Cloud deployment
* ✅ Secure Firebase configuration using environment variables

## ⚙️ Installation & Setup

Clone repository:

```bash
git clone https://github.com/tabisso/amazonFullLast
cd amazonClone
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm start
```

App runs at:

```
http://localhost:3000
```

---

## 🔑 Environment Variables

Create `.env` file:

```
REACT_APP_FIREBASE_API_KEY=your_key
REACT_APP_AUTH_DOMAIN=your_domain
```
